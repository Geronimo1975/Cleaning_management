Parameters Help

The parameters field accepts JSON objects that control the report generation. Here are some examples:

{
  "include_inactive": false,
  "min_rating": 3,
  "sort_by": "rating",
  "limit": 10
}

Parameters vary by report type:

  • Cleaner Performance: min_rating, include_inactive, sort_by
  • Company Revenue: include_cancelled, group_by
  • Job Statistics: job_types, status, limit
  • Contract Status: status, sort_by, group_by
  • Custom Report: Any required parameters for your custom report
